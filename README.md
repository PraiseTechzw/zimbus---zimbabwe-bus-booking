## 🌟 Features

- **🚀 Real-time Search**: Find the best bus routes across Zimbabwe instantly.
- **🛋️ Interactive Seat Selection**: Pick your preferred seat with our intuitive bus layout map.
- **💎 Premium Design**: A modern interface featuring glassmorphism, micro-animations, and a mobile-first approach.
- **👤 User Dashboard**: Manage your profile, view booking history, and track upcoming trips.
- **🔔 Smart Notifications**: Stay updated with booking confirmations, delays, and schedule changes.
- **💳 Multi-Payment Support**: Mock integration for Visa, Mastercard, and mobile payments (EcoCash).
- **🛡️ Secure Auth**: Integrated Google Authentication for a seamless and safe login experience.
- **📈 Operator Ratings**: View and compare different bus operators based on reviews and amenities.

## 🛠️ Tech Stack

- **Frontend**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 4.0](https://tailwindcss.com/)
- **State Management**: React Hooks (useState, useEffect)
- **Database & Auth**: [Firebase](https://firebase.google.com/) (Firestore, Auth)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: [Motion](https://motion.dev/) (motion/react)
- **Fonts**: [Outfit](https://fonts.google.com/specimen/Outfit) via Google Fonts

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (latest LTS version)
- A [Firebase Project](https://console.firebase.google.com/)

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/PraiseTechzw/zimbus---zimbabwe-bus-booking.git
    cd zimbus---zimbabwe-bus-booking
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Firebase Configuration:**
    Ensure you have your `firebase-applet-config.json` in the root directory. If you are using your own Firebase project, replace the config with your own web app details.

4.  **Run Locally:**
    ```bash
    npm run dev
    ```
    The app will be available at `http://localhost:3000`.
